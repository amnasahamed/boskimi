## 2024-04-09 - Debouncing Canvas Initialization on Resize
**Learning:** The codebase previously attached un-debounced `window.addEventListener('resize')` handlers that triggered complete re-initialization of large canvas particle arrays (`StarfieldBackground`, `CosmicDust`). This codebase-specific pattern caused severe CPU spikes and frame drops during window resizing due to redundant garbage collection and memory allocation per frame.
**Action:** When using `<canvas>` for background animations or complex visual components that track window dimensions, always debounce the `window.resize` event listeners (e.g., using a 200ms `setTimeout`) to prevent excessive array re-initialization, while ensuring an immediate un-debounced initial call is executed on mount to prevent rendering delays.
