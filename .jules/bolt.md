## 2024-05-24 - Canvas Resize Debouncing Gotcha\n**Learning:** When debouncing heavy re-initialization logic (like particle arrays) inside a window resize event on a canvas, you cannot simply debounce the *entire* resize handler. If you delay updating `canvas.width` and `canvas.height`, the canvas visually stretches and squashes during the resize drag, creating horrible jank. \n**Action:** Always split canvas resize logic into two parts: immediately update the dimension attributes to prevent CSS stretching, and debounce only the computationally expensive rendering state updates (like generating new star/particle objects).
