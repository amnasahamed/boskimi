## 2024-03-24 - Efficient array updates in high-frequency React hooks\n**Learning:** In `components/landing/global-impact.tsx`, a `setInterval` runs every 50ms to update the `dataPackets` array, currently using `.map(...).filter(...)`. This is an O(N) chained operation that creates an intermediate array every 50ms, causing unnecessary garbage collection pressure and CPU usage.\n**Action:** Use a single-pass transformation like `.reduce()` or a standard `for` loop to optimize high-frequency array updates, preventing intermediate array allocations.
