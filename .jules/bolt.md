## 2024-05-18 - [Canvas Array Initialization Bottleneck]
**Learning:** Found a critical performance bottleneck in `components/ui/starfield-background.tsx` and `components/ui/cosmic-dust.tsx` where an expensive array re-initialization mapping over `Math.random()` occurred directly on every single `window.resize` event without debouncing. This caused significant main-thread CPU blocking because `canvas.width * canvas.height / 3000` equates to thousands of items synchronously recreated for every resize pixel.
**Action:** Always debounce `window.resize` handlers containing expensive computational or DOM/Canvas setup (like rebuilding multi-thousand item arrays), aiming for a typical 200ms delay. Ensure the setup function is still explicitly called *once* outside the event listener on initial component mount to avoid a blank canvas before the first resize event triggers.
